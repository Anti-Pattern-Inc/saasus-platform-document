Build a silo-model SaaS with dedicated servers and databases for each tenant.  
Configure permissions and templates in the SaaS Development Console to start provisioning dedicated resources in your AWS environment when a tenant is created.

Related API links use operation names from Auth API.

## Provisioning settings

Manage whether automatic provisioning is enabled, permissions for AWS access, and the files used for provisioning and initialization.  
Prepare AWS CloudFormation templates and initialization SQL for your SaaS architecture.

## Tenant onboarding

Provision a dedicated application environment for a tenant and initialize its database when the tenant is created.  
Check provisioning status through the `TenantOnboardingStatus` tenant attribute on the tenant management page in the SaaS Operations Console.

Provisioning continues after the tenant is created. Check the SaaS Operations Console to confirm completion.

<FeatureTable>

| Feature | Details | Related APIs |
| --- | --- | --- |
| Automatically provision dedicated tenant environments | When infrastructure management is enabled, creating a tenant starts provisioning and initialization using the registered template and SQL.<br />References: [SaaS Infrastructure Management](/docs/part-4/saas-infra-management) | [CreateTenant](/docs/reference/auth-api#tag/tenant/operation/CreateTenant) |
| Check onboarding progress | Check the `TenantOnboardingStatus` tenant attribute in tenant information for preparation, database initialization, completion, or failure. Contact support if provisioning fails.<br />References: [SaaS Infrastructure Management](/docs/part-4/saas-infra-management) | [GetTenant](/docs/reference/auth-api#tag/tenant/operation/GetTenant) [GetTenants](/docs/reference/auth-api#tag/tenant/operation/GetTenants) |

</FeatureTable>

Onboarding runs in the Tokyo Region (ap-northeast-1).  
Automatic deletion of dedicated resources when a tenant is deleted (offboarding) is not supported.  
This feature is not available on legacy Starter and Standard plans; see the reference guide for availability.
