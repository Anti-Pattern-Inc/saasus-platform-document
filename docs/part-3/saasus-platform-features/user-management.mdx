Manage users registered with your SaaS and add them to or remove them from tenants.  
A SaaS user represents a user across the service, while a tenant user represents that user's membership in a specific tenant.  
One SaaS user can belong to multiple tenants.

Related API links use operation names from Auth API.

## SaaS users

Manage sign-in information and attributes for users registered with your service.  
Use the SaaS Operations Console for daily administration, and integrate APIs when building your own administration pages or user-facing information change features.  
Users register themselves through login page self-sign-up, while administrators use the user creation feature.

## Add and remove SaaS users from tenants

Add registered SaaS users to tenants and manage user information for each tenant.  
Add users to or remove them from tenants in the SaaS Operations Console, or integrate APIs to provide administration features in your own application.  
Your application implements access decisions for its pages and features using the retrieved tenant memberships and roles.
