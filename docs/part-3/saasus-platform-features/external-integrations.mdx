Integrate with Stripe for billing, deliver events to Amazon EventBridge, and integrate with AWS Marketplace.  
Alongside the external service configuration, implement event handling and tenant association in your SaaS application.

Related API links use operation names from Billing API, Auth API, Pricing API and Integration API.

## Stripe integration

Synchronize pricing plans, tax rates, tenants, and usage managed in SaaSus Platform with Stripe for billing.  
Configure the connection in the SaaS Development Console; synchronization then follows plan application and usage recording.  
If you do not use Stripe, implement billing using the pricing, subscription, and usage information you retrieve.

### Payment pages

SaaSus Platform instructs Stripe to create or update subscriptions when pricing plans are applied or changed.  
SaaSus Platform does not provide pages for card entry or 3D Secure authentication. Integrate Stripe’s Hosted Invoice Page or similar features when these pages are needed.

### Receiving payment events

To send emails after payment or detect refunds, receive Stripe webhooks directly on your SaaS application’s server.  
SaaSus Platform does not relay Stripe webhook events.

### Operations performed in Stripe

Perform the following operations in the Stripe Dashboard:

- Refund payments and reissue invoices
- Configure invoice payments using bank transfers or other non-card payment methods
- Apply individual discounts using coupons

Apply coupons to the Stripe customer or subscription associated with the target tenant.  
Changing pricing plan or pricing unit configurations directly in Stripe can cause inconsistencies with SaaSus Platform. Make changes to synchronized pricing definitions in SaaSus Platform.

## Amazon EventBridge

Deliver events such as user and tenant creation to your AWS account.  
Configure the destination in the SaaS Development Console, then set up an event bus, rules, and targets in Amazon EventBridge.

## AWS Marketplace

Associate AWS Marketplace selling plans and customers with tenants.  
Login pages handle new customer registration; implement the association with an existing tenant in your application.

:::caution New use is suspended

The existing guide states that new use is suspended because the integration does not support changes to AWS Marketplace specifications.  
See [AWS Marketplace Integration](/docs/part-4/aws-marketplace-integration/aws-marketplace-integration) for availability.

:::
