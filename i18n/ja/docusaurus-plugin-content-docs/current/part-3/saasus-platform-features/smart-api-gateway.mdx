SaaSアプリケーションの処理をAPIとして公開し、テナントやユーザーに応じたアクセス制御を行う機能です。  
公開したAPIはSmart MCP Serverを通じてAIクライアントからも利用できます。

APIの公開・アクセス制御の設定やAPIキーの管理は、主にSaaSus Platform コンソールで行います。  
SaaSアプリケーションでは公開する処理を実装し、SDKを組み込みます。

関連APIはAPI Gateway APIの操作名で表記しています。

## API公開設定

接続先のSaaSアプリケーションや公開する処理を設定し、APIを公開する機能です。  
SaaS 開発コンソールで設定・公開し、SaaSアプリケーションには参考ガイドに従ってSDKやアノテーションを組み込みます。

対応SDKやインフラの前提条件は、[Smart API Gateway 機能](/ja/docs/part-4/smart-api-gateway-features/overview)を確認してください。  
ガイドでは、AWS上のApplication Load Balancer（ALB）配下で動作するJavaのWebアプリケーションを対象としています。

## アクセス制御

公開APIを利用できるユーザー・テナント、呼び出し回数の上限、アクセス元のIPアドレスを制限する機能です。  
APIキーやユーザーに付与された役割を使い、公開する処理に応じてアクセスを制御します。

テナント用とユーザー用のAPIキーを区別し、公開する処理に応じて設定します。

## Smart MCP Server

Smart API Gatewayで公開したAPIをMCPツールとして提供する機能です。  
APIを公開するとMCP Serverも自動で利用可能になり、AIクライアントに接続先と認証情報を設定して呼び出せます。

<FeatureTable>

| 機能 | 詳細 | 関連API |
| --- | --- | --- |
| 公開APIのMCPツール化・スキーマ連携 | Smart API GatewayでAPIを公開すると、Smart MCP ServerでもMCPツールとして利用できるようになります。API定義の変更はMCPツールのスキーマにも反映されます。<br />参考：[Smart MCP Server 機能](/ja/docs/part-4/smart-api-gateway-features/smart-mcp-server-overview) | [PublishApiGateway](/ja/docs/reference/apigateway-api#tag/smartApiGateway/operation/PublishApiGateway) |
| AIクライアントからの認証付きAPI利用 | MCP ServerのエンドポイントとAPIキーをAIクライアントに設定します。テナント・ユーザーに対応する認証情報を使って、公開APIを呼び出します。<br />参考：[Smart MCP Server 機能](/ja/docs/part-4/smart-api-gateway-features/smart-mcp-server-overview) | — |

</FeatureTable>
