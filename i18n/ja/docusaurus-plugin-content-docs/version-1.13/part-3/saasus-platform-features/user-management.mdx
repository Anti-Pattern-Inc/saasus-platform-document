SaaS に登録されたユーザーの情報を管理し、テナントへの追加・テナントからの削除を行う機能です。  
SaaSユーザーはサービス全体のユーザー、テナントユーザーは特定のテナントに所属するユーザーを表します。  
1人のSaaSユーザーは、複数のテナントに所属できます。

関連APIはAuth APIの操作名で表記しています。

## SaaSユーザー

サービスに登録されたユーザーのログイン情報や属性を管理する機能です。  
日々の管理はSaaS 運用コンソールで行い、SaaSアプリケーションに管理画面や利用者向けの情報変更機能を作る場合にAPIを組み込みます。  
利用者自身の登録にはログイン画面のセルフサインアップ、管理者による登録にはユーザー作成機能を使います。

## SaaSユーザーをテナントへ追加・削除

登録済みのSaaSユーザーをテナントに追加し、テナントごとのユーザー情報を管理するための機能です。  
テナントへの追加・テナントからの削除はSaaS 運用コンソールで行え、SaaSアプリケーションで管理機能を提供する場合はAPIを組み込みます。  
取得したテナントや役割の情報を使った画面・機能の利用可否の判定は、SaaSアプリケーションで実装します。
