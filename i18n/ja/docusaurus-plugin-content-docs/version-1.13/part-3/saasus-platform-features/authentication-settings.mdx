SaaSのドメインやAPI接続情報、ログイン画面の表示・認証設定、通知メールを管理する機能です。  
ログインやMFA、トークン交換の実装については、[認証・ログイン](/ja/docs/part-3/saasus-platform-features/authentication)を参照してください。

関連APIはAuth APIの操作名で表記しています。

## 基本設定

ログイン画面や通知メールに使うドメイン名、ログイン後の遷移先URL、SaaSus APIの呼び出しに使う接続情報を設定する機能です。  
SaaS 開発コンソールで、ドメイン名や遷移先URLの設定、SaaS ID・APIキー・クライアントシークレットの確認・管理を行えます。

## 認証詳細設定

ログイン画面の見た目やリンク、パスワード要件、セルフサインアップの許可、通知メールを設定する機能です。  
表示に関する設定はログイン画面を対象とし、パスワード要件と登録許可は認証・登録処理にも適用されます。  
通知メールは、送信元・返信先と、新規登録・パスワード再設定・MFAなどの種類ごとの件名・本文を設定できます。

SaaS 開発コンソールから表示設定を編集でき、保存後はログイン画面への反映に時間がかかる場合があります。

### ログイン画面のカスタマイズ範囲

サービス名・ロゴ・ファビコンやリンクの表示を設定できますが、配色の変更、任意のHTML/CSSの反映、お知らせ文の追加には対応していません。  
独自のデザインやお知らせを表示する場合は、SaaSus APIを利用した独自ログイン画面を実装します。  
実装方法は[認証API実装ガイド](/ja/docs/part-6/implementation-guide/auth/overview)を参照してください。
