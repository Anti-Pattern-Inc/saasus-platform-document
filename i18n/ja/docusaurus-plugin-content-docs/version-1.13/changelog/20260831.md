以下の機能追加および不具合の修正についてリリースを行いました。

- リフレッシュトークンの有効期限を設定可能にしました  
  これまでリフレッシュトークンの有効期限は30日間の固定値となっておりましたが、長時間にわたってログイン状態を維持したいというご要望を受け、有効期限を任意に設定できる機能を追加いたしました。  

  変更内容  
  - SaaS 開発コンソールにて、リフレッシュトークンの有効期限を設定できるようになりました。  

  　■ ご利用にあたっての注意点  
  　　設定変更を反映するには、対象ユーザーの再ログインが必要です。  
  　　有効期限を長期に設定される場合は、トークン漏洩時のリスクについて十分にご留意ください。  

- 従量課金プラン解約時の消費税率設定に関する不具合を修正しました  
  プラン解約時のダイアログで任意の税率を選択できる状態となっており、解約元のプランと異なる税率が誤って設定される場合がある事象を確認いたしました。  
  本事象について、以下のとおり挙動を修正いたしました。  

  変更内容  
  - プラン解約ダイアログから、税率選択のドロップダウンを削除しました。  
  - 解約操作時には、現在契約中のプランに設定されている税率が自動的に引き継がれるようになりました。（現在のプランに税率が設定されていない場合は、税率なしで解約されます。）  

  　■ APIへの影響  
  　　解約APIに税率のパラメータを送信した場合でも、当該の値は無視され、現在契約中のプランの税率が自動的に適用されます。  
  　　API自体の仕様に変更はありませんが、解約時に指定いただいた税率は反映されなくなります。  

  　■ 本修正による影響のない範囲  
  　　通常のプラン変更時、および初回のプラン設定時における税率の指定は、従来どおりご利用いただけます。
