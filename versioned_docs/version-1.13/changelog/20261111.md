We have released the following improvements.

- Authentication screen security improvements  
  SaaSus Platform no longer includes email addresses in URLs when users move between its sign-in, sign-up confirmation, password reset, and related screens.  
  This prevents email addresses from being recorded in access logs and browser history during these screen transitions.  

- Library vulnerability fixes  
  We updated internal libraries to address vulnerabilities.
