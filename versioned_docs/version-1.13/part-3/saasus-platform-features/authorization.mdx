These features define roles and environments for SaaS authorization and additional fields for users and tenants.  
Use the roles and environments assigned to users to control access to pages and features in your SaaS application.

Related API links use operation names from Auth API.

## Role definitions

Define roles such as administrator or regular user and assign them per tenant and environment.  
Define roles in the SaaS Development Console and assign or remove them in the SaaS Operations Console.  
Your application implements access control for its pages and features based on those roles.

## Attribute definitions

Define fields for additional user or tenant information, such as names, departments, or notes.  
Define tenant user and tenant attributes in the SaaS Development Console; define SaaS user attributes through SaaSus API.  
Defining attribute fields is separate from updating values for individual users or tenants.

## User environment definitions

Define the environments users can access and their roles in each environment. For example, assign a user the administrator role for testing and the regular user role for production, and have your SaaS application determine which operations are allowed.  
These definitions are separate from the environments you switch between in the SaaSus Platform Console.

| --- | --- | --- |
| List, retrieve, create, update, and delete user environment definitions | Manage environment IDs, names, and display names.
