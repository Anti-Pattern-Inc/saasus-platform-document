Publish application operations as APIs and control access by tenant and user.  
Published APIs can also be accessed by AI clients through Smart MCP Server.

API publishing, access control settings, and API key management are primarily handled in the SaaSus Platform Console.  
Implement the operations to publish and integrate the SDK in your SaaS application.

Related API links use operation names from API Gateway API.

## API publication settings

Configure the connected SaaS application and the operations to expose, then publish APIs.  
Configure and publish APIs in the SaaS Development Console, and integrate the SDK and annotations into your application following the reference guide.

See [Smart API Gateway Features](/docs/part-4/smart-api-gateway-features/overview) for supported SDKs and infrastructure requirements.  
The guide covers Java web applications running behind an Application Load Balancer (ALB) on AWS.

## Access control

Restrict which users and tenants can access published APIs, how often they can call them, and which source IP addresses are allowed.  
Use API keys and roles assigned to users to control access to each published operation.

Distinguish tenant API keys from user API keys and configure access for each operation.

## Smart MCP Server

Expose APIs published through Smart API Gateway as MCP tools.  
Publishing the APIs also makes the MCP server available automatically. Configure its endpoint and authentication credentials in an AI client to call the tools.

<FeatureTable>

| Feature | Details | Related APIs |
| --- | --- | --- |
| Expose published APIs as MCP tools | When you publish an API through Smart API Gateway, it also becomes available as an MCP tool through Smart MCP Server. Changes to the API definition are also reflected in the MCP tool schema.<br />References: [Smart MCP Server Feature](/docs/part-4/smart-api-gateway-features/smart-mcp-server-overview) | [PublishApiGateway](/docs/reference/apigateway-api#tag/smartApiGateway/operation/PublishApiGateway) |
| Call APIs from authenticated AI clients | Configure the MCP server endpoint and API key in the AI client. Call published APIs using credentials associated with the appropriate tenant or user.<br />References: [Smart MCP Server Feature](/docs/part-4/smart-api-gateway-features/smart-mcp-server-overview) | — |

</FeatureTable>
