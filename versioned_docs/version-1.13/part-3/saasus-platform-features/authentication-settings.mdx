Manage SaaS domains and API credentials, login page appearance and authentication settings, and notification emails.  
See [Authentication and sign-in](/docs/part-3/saasus-platform-features/authentication) for implementing sign-in, MFA, and token exchange.

Related API links use operation names from Auth API.

## Basic settings

Configure the domains used for login pages and notification emails, the redirect URL after sign-in, and credentials for calling SaaSus APIs.  
Use the SaaS Development Console to configure domains and redirect URLs, and to view and manage the SaaS ID, API keys, and client secret.

## Advanced authentication settings

Configure login page appearance and links, password requirements, self-sign-up permissions, and notification emails.  
Appearance settings apply to the login pages; password requirements and sign-up permissions also apply to authentication and registration processing.  
Configure the sender and reply-to addresses and the subject and message for each email type, including registration, password recovery, and MFA.

Edit appearance settings in the SaaS Development Console. Changes can take time to appear on the login pages after saving.

### Login page customization options

You can configure the service name, logo, favicon, and link visibility. Changing colors, applying custom HTML/CSS, and adding announcements are not supported.  
To use a custom design or display announcements, implement custom sign-in pages with SaaSus API.  
See the [Authentication API Implementation Guide](/docs/part-6/implementation-guide/auth/overview) for implementation details.
